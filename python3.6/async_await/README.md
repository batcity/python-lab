# TODO: Async / Await and Coroutines:

Coroutines are a specific type of function (aka subroutine) that allows for running non blocking code, this helps save CPU cycles when performing IO (such as downloading files, reading from databases etc)

Before Python 3.6 coroutines were not natively supported in python
